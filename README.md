# A* Maze Solver & Pathfinding Visualizer

A Python-based interactive pathfinding application that demonstrates the **A* search algorithm** through a graphical maze environment. Users can create custom mazes, generate procedural obstacles, configure heuristic and movement options, and visualize the search process and resulting shortest path in real time.

## Features

* Interactive maze creation and wall editing
* A* shortest-path visualization
* Multiple heuristic functions: Manhattan, Euclidean, Chebyshev, and Octile
* Configurable diagonal movement
* Recursive Backtracker and Random Obstacle maze generation
* Real-time pathfinding performance statistics
* Instant and step-by-step solving modes
* Automated unit tests

## Technologies

**Python 3.8+ | Tkinter | A* Algorithm | Unit Testing**

## Purpose

This project provides a practical visualization of **heuristic-based pathfinding**, demonstrating how A* efficiently searches a grid environment to find an optimal path while allowing users to experiment with different heuristics and movement configurations.
